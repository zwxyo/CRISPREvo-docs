# Citation & attribution

## Citing CRISPREvo

A formal CRISPREvo manuscript citation is not yet provided here. Use the source repository and the exact software version for attribution until a preferred citation becomes available.

Until then, cite the CRISPREvo source repository and record the exact release tag or Git commit used:

> CRISPREvo: CRISPR evolutionary analysis web platform. Source code: https://github.com/zwxyo/crisprevo

## Underlying tools and services

Cite the methods used in your run as appropriate:

- [CRISPRCasFinder](https://github.com/dcouvin/CRISPRCasFinder) for CRISPR detection.
- [NCBI](https://www.ncbi.nlm.nih.gov/) records, E-utilities and NCBI Datasets for retrieved sequences and assemblies.
- NCBI BLAST and target accessions for SpacerTarget searches; retain search date, database, hit limit, filters and the report.
- The GraphMSA or CRISPRFormer method used for tree inference, once the project-specific preferred citations are supplied.

The documentation structure and task-oriented style were informed by the [CRISPR Comparison Toolkit documentation](https://crispr-comparison-toolkit.readthedocs.io/en/latest/), particularly its separation of quick usage, tutorials, input contracts, and tool-specific pages. CRISPREvo behavior described here is based on the current CRISPREvo web implementation.

## Information to record

For reproducibility, report the CRISPREvo release/commit, access date, input source, processing settings, SpacerMap alignment and clustering, color seed, tree method, repeat-distance setting, CRISPRFormer profile where applicable, any chosen root, and manual edits made in ArrayPhyloViz. Keep original inputs, settings and downloaded outputs separately: private results links expire after seven days, and saved reports do not retain every submitted parameter.
